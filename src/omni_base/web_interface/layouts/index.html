LUMI Control Panel Layouts

Six takes on the same control panel. Every one is fully functional and shares identical logic, so pick purely on feel.

Before you open one: the robot must be running with the web bridge enabled — ros2 launch omni_base navigation.launch.py use_voice:=true use_web:=true
On first load, enter the Pi's address as ws://<pi-ip>:9090 and press Connect. The address is remembered on that tablet and reconnects by itself on every later visit.

Kiosk

Enormous destination tiles, plain wording, and a full-width stop button. Technical controls are tucked behind a settings gear so a visitor cannot wander into teleop.

Immersive

Your DeepSeek design, now wired up. Edge-to-edge map with frosted glass panels floating over it. The most striking option, and the map gets the most room.

Console

Three columns with everything visible at once: modes, teleop, topic health, and a live log. Refined version of the original interface, now touch-capable.

Map on the left, a tabbed panel on the right grouping Go, Drive, Express, and Setup. Keeps the screen calm while still exposing every control within one tap.
